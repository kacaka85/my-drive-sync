Privacy Policy

Last updated: October 21, 2026

1. Application Purpose

Personal Google Drive Sync is a personal-use application for synchronizing files between a Linux computer and the user's Google Drive account.

2. Data Access

The application accesses Google Drive files and metadata as necessary to perform file synchronization. Access is authorized through Google OAuth 2.0.

3. Data Storage and Sharing

Files are synchronized between the user's local computer and Google Drive. The application does not intentionally transmit file contents to third-party services. Authentication credentials are stored locally by the synchronization software.

4. Data Usage

Google Drive data is used solely to perform synchronization operations requested by the user. Data is not sold or used for advertising.

5. Data Security

Google OAuth 2.0 is used for authorization. Access can be revoked at any time through the user's Google Account security settings.

6. Data Retention and Deletion

Local synchronized files remain on the user's computer until deleted by the user or synchronization software. OAuth credentials can be removed from the synchronization software.

7. Contact

For privacy inquiries, contact the application administrator through the associated GitHub repository.
