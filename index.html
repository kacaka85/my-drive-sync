my-drive-sync

About the Application

my-drive-sync is a personal-use application that synchronizes files and folders between a Linux computer and Google Drive.

Application Features

  • Upload files from Linux to Google Drive.
  • Download files from Google Drive to Linux.
  • Synchronize changes between local folders and Google Drive.

Google Drive Permissions

The application requests access to Google Drive files and metadata to perform synchronization operations authorized by the user. Depending on the synchronization configuration, these operations may include creating, reading, updating, and deleting files.

Privacy

This application is intended for personal use and does not sell user information or use Google Drive data for advertising.
